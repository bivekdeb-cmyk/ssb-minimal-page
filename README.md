# SSB minimal page

The Scaler School of Business minimal home page, on its own. It is the `/v9` page from
[Scaler-LLM-Experiments/SSB---Page](https://github.com/Scaler-LLM-Experiments/SSB---Page/tree/ssb-minimal)
at commit `68f41ea`, served here at `/`. The other page versions (v3, v6–v8, final), their sections
and their images were left out.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

`CLAUDE.md` and `AGENTS.md` are copied from the original repo, so they still describe the
other pages and routes that were taken out.
